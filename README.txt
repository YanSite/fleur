Флаувер — сайт-экспозиция (статический HTML)

Состав:
  index.html            страница
  js/flauver-scroll.js  WebGL-движок фото, переходов и камеры (без зависимостей)
  js/runtime.js         лёгкий шаблонизатор страницы
  img/                  фотографии работ (JPEG)

Как выложить: загрузить папку целиком на любой статический хостинг
(Netlify, Vercel, GitHub Pages, S3, обычный веб-сервер). Сборка не нужна.

Важно: открывать через веб-сервер (http/https). Если открыть index.html
двойным щелчком с диска, браузер запретит WebGL читать фото.
Для просмотра с диска используйте flauver.html — в нём всё в одном файле.

Локальный просмотр: в папке выполнить  python3 -m http.server  и открыть http://localhost:8000

Шрифты Onest и IBM Plex Mono подгружаются с Google Fonts.
Контактов (телефон, Telegram, адрес, часы) на странице пока нет — добавить в раздел «Контакты» в index.html.
